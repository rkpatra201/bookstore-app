# bookstore-app

## Build And Run Steps For Local Environment.

1. Install Node Js 24
2. Install JDK 17
3. Install Maven 3.9
4. Clone this github repository
<img width="2910" height="946" alt="image" src="https://github.com/user-attachments/assets/243a20d7-5737-47d0-a0f5-c025d9f2f55a" />
5. The repository has 2 folders. bookstore-backend and bookstore-frontend.

## Backend : Build and Start the Application

1. Navigate to bookstore-backend

<img width="2614" height="192" alt="image" src="https://github.com/user-attachments/assets/209a9be0-e79d-444e-9951-cf01c20a58ec" />


2. Build command : `mvn clean install`
